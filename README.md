# AI Assistant (Multi-tenant)

## Tech
- Next.js
- MongoDB
- Mongoose
- Zod

## Features
- Multi-tenant (project + product instance)
- Chat system
- Admin dashboard (config-driven)
- Access control (admin only)
- Integration simulation

## Setup
npm install
npm run dev

## Config-driven dashboard
Edit MongoDB:
adminDashboardConfigs → change labels → UI updates
