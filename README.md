# 📖 About

PHISHGUARD AI is a browser security extension developed to help users browse the web more safely by detecting potentially malicious and phishing websites in real time.

Instead of relying on a single detection technique, the extension performs layered security analysis using multiple specialized detection engines. Each engine evaluates different website characteristics such as URL patterns, webpage content, brand similarity, navigation behaviour, hidden elements, and user interaction signals before generating a final security assessment.

The modular architecture allows each engine to contribute evidence independently, resulting in a more comprehensive website analysis.

# 🔍 Detection Modules

## 🔗 URL Engine

Analyzes URL characteristics including protocol usage, suspicious keywords, and abnormal URL structures that are commonly associated with phishing websites.

---

## 🌐 Page Engine

Inspects webpage content and searches for indicators such as login forms, credential requests, phishing-related keywords, and suspicious page elements.

---

## 🏷️ Brand Engine

Detects possible brand impersonation by comparing domain names against well-known brands and identifying suspicious similarities.

---

## 🧠 Behaviour Engine

Monitors user interaction patterns including rapid clicks, typing behaviour, and suspicious form submissions that may indicate phishing attempts.

---

## 🧭 Navigation Engine

Evaluates webpage navigation information such as referrer availability and navigation behaviour to identify unusual browsing patterns.

---

## 🕵️ Scraping Engine

Scans webpages for hidden forms and concealed elements that are frequently used in phishing attacks.

---

## 📑 Evidence Engine

Collects evidence generated by all detection modules and organizes the identified security indicators.

---

## ⚖️ Decision Engine

Combines the scores from every detection engine and determines whether the website is:

- ✅ Safe
- ⚠️ Suspicious
- 🚨 Phishing

---

## 📊 Report Generator

Creates a structured security report containing:

- Website URL
- Domain
- Detection Score
- Threat Status
- Detection Reasons
- Timestamp

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/anjali4177/PHISHGUARDai.git
```

---

## Enable Developer Mode

Open Chrome and visit

```
chrome://extensions
```

Enable **Developer Mode**.

---

## Load Extension

Click

```
Load unpacked
```

Select the **PHISHGUARD AI** project folder.

The extension is now ready for use.

---

# 🚀 Workflow

1. User opens a webpage.
2. Website information is collected.
3. Security engines analyze different webpage components.
4. Evidence from every engine is combined.
5. Decision Engine calculates the final threat score.
6. A warning popup is displayed if the website appears suspicious.

---

# 🔒 Privacy

PHISHGUARD AI is designed to perform website analysis locally inside the browser without requiring unnecessary user information.
